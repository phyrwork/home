# T0031 — Battery integration cleanup and local release gate

Status: Implemented — approved for local commit

Depends on: T0030

## Objective

Delete every superseded path, consolidate tests and current documentation around
observable behavior, and prove the complete lean integration locally. Add no new
control behavior.

## Required source shape

Production is limited to:

```text
house_battery_control/
├── __init__.py
├── config.py
├── model.py
├── planner.py
├── solis.py
├── controller.py
├── sensor.py
└── manifest.json
```

There is one controller, planner and Solis writer/lock. No compatibility adapter,
generic transaction, reentrant lock, cleanup task or workflow framework remains.

Delete all absorbed Python modules and abstraction-specific tests, including
`const`, `contracts`, `coordinator`, `domain_constants`, `energy`, `ha_writer`,
`interval`, `load`, `octopus_windows`, `reserve_planner`, `runtime_inputs`,
`solis_actuator`, `solis_config`, `solis_policy`, `solis_reader`, `solis_state`,
`strategy`, and `write_contracts`. Delete tracked/generated bytecode.

  use `delete: yes`, so the obsolete HA files will be removed at deployment.

  architecture. T0022, T0024 and T0025 retain their historical evidence but are
  explicitly superseded.
